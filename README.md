# js & ts
ts是typescript, 是JavaScript的超集，会有语法检查

直接在html中使用ts，浏览器可能会将ts判断成视频，导致报错，所以需要在html中载入js文件

所以使用typescript做开发，开发后将ts文件编译成js文件再部署
